# ABS-GF-FDM-ML-XAI-Optimization

## Machine Learning Assisted Optimization of ABS–Glass Fiber FDM Printing Parameters

This repository presents a complete machine learning workflow for predicting and optimizing FDM additive manufacturing performance using experimental data, virtual design exploration, explainable AI, and multi-objective optimization.

---

## Research Workflow

Experimental Data  
↓  
Data Processing & Analysis  
↓  
Design of Experiments (DOE)  
↓  
Machine Learning Modeling  
↓  
Explainable AI (SHAP/PDP)  
↓  
Sensitivity Analysis  
↓  
NSGA-II Multi-objective Optimization  

---

## Objectives

- Predict tensile strength of ABS-GF printed parts
- Predict surface roughness
- Identify important process parameters
- Develop ML-based surrogate models
- Optimize printing conditions using NSGA-II

---

## Input Parameters

- Glass Fiber content
- Infill density
- Layer thickness
- Nozzle temperature
- Bed temperature
- Printing speed

## Output Responses

- Tensile strength (MPa)
- Surface roughness (µm)


# ABS-GF-FDM-ML-Optimization

Machine learning based optimization framework for ABS-glass fiber FDM additive manufacturing.

## Project Overview

This project applies machine learning, explainable AI, sensitivity analysis, and multi-objective optimization for improving FDM printing performance.

## Objectives

- Predict tensile strength
- Predict surface roughness
- Compare machine learning models
- Analyze important process parameters
- Optimize printing conditions using NSGA-II

## Methods

Machine Learning:
- XGBoost
- CatBoost
- Extra Trees
- Neural Network

Explainable AI:
- SHAP analysis
- Feature importance

Optimization:
- Multi-objective NSGA-II optimization

## Project Structure

Code - Jupyter notebooks

Data - Experimental and simulation datasets
