# ABS-GF-FDM-ML-Optimization

Machine learning based optimization framework for ABS-glass fiber FDM additive manufacturing.

## Project Overview

This project applies machine learning, explainable AI, sensitivity analysis, and multi-objective optimization for improving FDM printing performance.

## Objectives

- Predict tensile strength
- Predict surface roughness
- Compare machine learning models
- Analyze important process parameters
- Optimize printing conditions using NSGA-II

## Methods

Machine Learning:
- XGBoost
- CatBoost
- Extra Trees
- Neural Network

Explainable AI:
- SHAP analysis
- Feature importance

Optimization:
- Multi-objective NSGA-II optimization

## Project Structure

Code - Jupyter notebooks

Data - Experimental and simulation datasets

Results - Generated figures and outputs
