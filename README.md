# ABS-GF-FDM-ML-XAI-Optimization

## Machine Learning Assisted Optimization of ABS–Glass Fiber FDM Printing Parameters


## Project Overview

This project develops a machine learning-based framework for predicting and optimizing the performance of ABS–glass fiber fused deposition modeling (FDM) processes.

The framework integrates experimental data analysis, design of experiments, machine learning prediction, explainable artificial intelligence (XAI), sensitivity analysis, and multi-objective optimization to identify optimal printing conditions.

The main objectives are:

- Predict tensile strength
- Predict surface roughness
- Identify critical FDM process parameters
- Explain model predictions using SHAP analysis
- Optimize printing parameters using NSGA-II

## Methodology

The workflow consists of:

1. Experimental data collection and preprocessing

2. Virtual design space exploration using DOE

3. Machine learning model development

4. Explainable AI analysis

5. Global sensitivity analysis

6. Multi-objective optimization
